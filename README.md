# Webovio — Creative Agency Landing Page

A responsive HTML and SCSS layout exercise for a creative agency website.

**Stack:** HTML · SCSS · JavaScript

## Features

- Hero, partner logos, project stories, testimonials and service sections.
- Mobile navigation toggle.
- SCSS split into header, main, footer and responsive partials.
- Included design reference in `макеты.pdf`.

## Run locally

Open `webovio/webovio.html` in a browser. The root `index.html` also links to this page. Compiled CSS is included; no package installation is required.

For styling changes, compile `webovio/style.scss` to `webovio/style.css` with Sass.

## Structure

- `webovio/webovio.html` — main page.
- `webovio/webovio.js` — navigation interaction.
- `webovio/components/` — SCSS partials.
- `webovio/img/` — page assets.

## Scope

A static frontend layout study. Content and visual assets are included as part of the exercise; no backend is implemented.
